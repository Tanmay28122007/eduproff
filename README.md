# Eduproff

A certificate verification platform built with React, TypeScript, Vite, shadcn-ui, and Tailwind CSS.

## Tech Stack

- **Vite** — fast build tooling
- **TypeScript** — type-safe development
- **React** — UI library
- **shadcn-ui** — accessible component primitives
- **Tailwind CSS** — utility-first styling
- **Supabase** — authentication, database, and edge functions

## Getting Started

Install dependencies and start the development server:

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Step 3: Install dependencies
npm install

# Step 4: Start the development server
npm run dev
```

**Use GitHub Codespaces**

- Navigate to the main page of your repository.

- Click "New codespace" to launch a new Codespace environment.
- Edit files directly within the Codespace and commit when done.

## Deployment

Build the production bundle:

```sh
npm run build
```

The output will be in the `dist/` directory. Deploy to any static hosting provider (Vercel, Netlify, Cloudflare Pages, etc.).

Refer to your hosting provider's documentation to connect a custom domain to your deployed application.
